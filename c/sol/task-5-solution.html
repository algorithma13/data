Решение C5: Максимална медиана

Школа МГ
Тема: Двоично търсене по отговора
C++ Оптимално решение

Пълното авторско решение на задачата. Включва функция check, която пресмята нужните операции само за елементите от средата до края на масива, и главен цикъл за двоично търсене по отговора.

#include <iostream> #include <vector> #include <algorithm> using namespace std; int n; long long k; vector<long long> a;

Функцията check(x) проверява дали можем да направим медианата поне x. Разглеждаме елементите от индекс n / 2 до края и натрупваме нужната разлика в променливата op.

bool check(long long x) { long long op = 0; for(int i = n / 2; i < n; i++) { if(x > a[i]) op += (x - a[i]); if(op > k) return false; } return true; }

В главната функция сортираме масива (за да работи логиката за дясната половина) и прилагаме стандартния шаблон за двоично търсене в интервала `[1, 2000000005]`.

int main() { ios_base::sync_with_stdio(false); cin.tie(NULL); cin >> n >> k; a.resize(n); for(int i = 0; i < n; i++) cin >> a[i]; sort(a.begin(), a.end()); long long low = 1; long long high = 2000000005LL; while(low + 1 < high) { long long mid = low + (high - low) / 2; if (check(mid)) low = mid; else high = mid; } cout << low << "\n"; }
