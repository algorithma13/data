Визуализация: Двоично търсене по отговора

Задача "Aggressive Cows": Търсим максималното възможно минимално разстояние между K крави в дадените обори. Натиснете "Зареди алгоритъма", за да започнете.

Код на алгоритъма (C++)

bool check(int x, const vector<int>& a, int k) { int cows_placed = 1; int last_pos = a[0]; for(int i = 1; i < a.size(); i++) { if(a[i] - last_pos >= x) { cows_placed++; last_pos = a[i]; if(cows_placed >= k) return true; } } return false; } int main() { int n, k; cin >> n >> k; vector<int> a(n); for(int i = 0; i < n; i++) { cin >> a[i]; } sort(a.begin(), a.end()); int low = 1; int high = a.back() - a.front() + 1; while(low + 1 < high) { int mid = low + (high - low) / 2; if(check(mid, a, k)) { low = mid; // Можем и повече, вдигаме долната граница } else { high = mid; // Твърде голямо е, сваляме горната граница } } cout << low << "\n"; return 0; }

Двоично търсене в интервала [low, high]

low (Възможно) mid (Тестваме X) high (Невъзможно)
- - -
Функция check(X=): Можем ли да сложим крави на разстояние поне ?
