ЗАДАЧА C4: Съвместимост

⏱️ Време: 0.18 с. 💾 Памет: 256 MB 🏢 Школа МГ

Екип в ІТ компания трябва да разработи нов софтуерен модул, който ще се използва от n различни клиентски системи.

Всяка клиентска система има свой собствен набор от софтуерни библиотеки (dependencies), от които зависи. За да може вашият нов модул да работи на всички клиентски системи безпроблемно, той трябва да използва само онези библиотеки, които са налични във всяка една от тези n системи.

Да се напише програма compatibility.cpp, която по даден брой на системите и списъците им с библиотеки определя кои от тях са общи за абсолютно всички системи. Всяка библиотека е представена с уникален идентификатор - малка латинска буква ('a'-'z').

Вход

На първия ред на стандартния вход ще се въведе едно цяло число n - броят на клиентските системи.

На следващите n реда ще се въведе по един низ, представляващ списък с наличните библиотеки за съответната система.

Изход

На един ред на изхода се извежда низ, съдържащ идентификаторите на всички общи библиотеки, сортирани по азбучен ред.

Ако няма нито една обща библиотека, програмата да извежда празен ред.

Ограничения

1 ≤ n ≤ 50000
Дължината на всеки низ е между 1 и 1000 символа.

Пример

Примерен вход Изход за примера
3
authentication
authorization
auditing		 aintu

Обяснение на примера

  • Библиотеки в система 1 {a, u, t, h, e, n, i, c, o}
  • Библиотеки в система 2 {a, u, t, h, o, r, i, z, n}
  • Библиотеки в система 3 {a, u, d, i, t, n, g}

След сравняване, единствените библиотеки, налични в трите системи са {a, i, n, t, u}. Подредени по азбучен ред, те образуват резултата "aintu".

💡 Указания: Букви като битове (Bitmasks)

Защо да правим масиви, когато имаме маски?

  • Английската азбука съдържа точно 26 малки букви ('a' до 'z'). Това означава, че 26 бита са напълно достатъчни! Те се побират идеално в стандартен 32-битов int. Няма нужда дори от long long.
  • Трансформация: За да превърнете буква c в номер на бит (индекс), просто извадете ASCII кода на 'a' от нея: int bit = c - 'a';. Така 'a' става 0-ви бит, 'b' е 1-ви и т.н.
  • Създайте маска за всяка система: mask |= (1 << (c - 'a')).
  • Намерете общите библиотеки чрез побитово И (&) на маските на всички системи.
  • Бонус: Автоматично сортиране! Тъй като битовете в int променливата са физически подредени (от 0 до 25), ако накрая обходите крайния резултат и отпечатате активните битове като символи char('a' + i), те ще излязат автоматично сортирани по азбучен ред!
