Анализ: Максимална медиана

🏆 Задача: C5
🎯 Тема: Двоично търсене по отговора

Основна идея

За да можем бързо да намерим отговора, първото нещо, което трябва да направим, е да сортираме масива във възходящ ред. Тъй като броят на елементите n е нечетен, първоначалната медиана винаги се намира точно на индекс n / 2.

Ще търсим оптималната медиана чрез двоично търсене в интервала на възможните отговори (от 1 до много голямо число). Основната ни задача е да напишем функцията check(x), която проверява: Можем ли да направим медианата да бъде поне x, използвайки най-много k операции?

💡 Защо разглеждаме само дясната половина?
Ако искаме средният елемент да стане поне x, трябва не само той, но и всички елементи вдясно от него също да станат поне x. В противен случай (тъй като масивът е сортиран), някой по-малък елемент отдясно ще се "плъзне" наляво и ще заеме мястото на медианата. Елементите в лявата половина не ни интересуват – те могат да си останат малки.

Функцията check(x)

Обхождаме масива от средата (n / 2) до края. Ако текущият елемент е по-малък от x, добавяме разликата x - a[i] към общия брой нужни операции. За оптимизация, ако нужните операции надхвърлят k преди да сме стигнали до края на масива, спираме рано и връщаме false.

bool check(long long x) {
    long long operations = 0;
    for (int i = n / 2; i < n; i++) {
        if (x > a[i]) {
            operations += (x - a[i]);
        }
        // Оптимизация: спираме рано
        if (operations > k) {
            return false;
        }
    }
    return true;
}

Двоично търсене (Главна функция)

В главната програма задаваме границите на двоичното търсене. Най-малката възможна медиана е 1. Най-голямата възможна медиана се постига, ако оригиналният масив има елемент 109 и добавим към него всичките 109 операции. Следователно горната граница (която е гарантирано невъзможна) е малко над 2 милиарда.

// 1. Сортираме масива
sort(a.begin(), a.end());

// 2. Търсим отговора
long long low = 1;
long long high = 2000000005LL;

while (low + 1 < high) {
    long long mid = low + (high - low) / 2;
    
    if (check(mid)) {
        low = mid; // Възможно е, опитваме по-нагоре
    } else {
        high = mid; // Невъзможно, сваляме границата
    }
}
cout << low << "\n"; // Отговорът винаги остава в low
