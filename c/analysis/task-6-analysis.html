Анализ: Конференция

🏆 Задача: C6 (USACO)
🎯 Тема: Двоично търсене по отговора

Основна идея

Задачата изисква от нас да минимизираме максималното време за чакане на кравите. Това е класически сигнал за двоично търсене по отговора. Първото нещо, което трябва да направим, е да сортираме времената на пристигане на кравите ti във възходящ ред, за да можем да ги качваме в автобусите хронологично.

Ще търсим оптималното време за чакане X в интервала от 0 до 109. Функцията check(x) ще отговаря на въпроса: "Възможно ли е да извозим всички крави с M автобуса с капацитет C, така че никоя крава да не чака повече от x време?"

💡 Алчен алгоритъм за check(x):
Когато тестваме дадено време x, се опитваме да съберем максимален брой крави във всеки автобус. Започваме нов автобус с първата чакаща крава (нека времето ѝ на пристигане е first_arrival). Продължаваме да качваме следващите крави в същия автобус, стига да са изпълнени двете условия:
1. В автобуса има свободни места (брой < C).
2. Нито една крава не чака прекалено дълго (ti - first_arrival ≤ x).
Ако някое от условията се наруши, този автобус тръгва и отваряме нов за текущата крава.

Функцията check(x)

bool check(long long x) {
    int buses_used = 1;
    int cows_in_current_bus = 0;
    long long first_arrival = t[0];

    for (int i = 0; i < N; i++) {
        // Ако автобусът се препълни ИЛИ времето за чакане стане твърде голямо
        if (cows_in_current_bus == C || t[i] - first_arrival > x) {
            buses_used++;             // Пускаме нов автобус
            first_arrival = t[i];     // Той стартира с тази крава
            cows_in_current_bus = 1;  // Качваме я
        } else {
            cows_in_current_bus++;    // Добавяме кравата в текущия автобус
        }
    }

    // Можем ли да се справим с най-много M автобуса?
    return buses_used <= M;
}

Двоично търсене (Главна функция)

sort(t.begin(), t.end());

long long low = -1; // Невъзможна граница отдолу
long long high = 1000000005LL; // Сигурна граница отгоре

while (low + 1 < high) {
    long long mid = low + (high - low) / 2;
    
    if (check(mid)) {
        high = mid; // Възможно е, опитваме с по-малко чакане
    } else {
        low = mid; // Невъзможно е, трябва да чакат повече
    }
}
cout << high << "\n"; // Отговорът е в high (първото true)
