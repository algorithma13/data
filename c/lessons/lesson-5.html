Приложения на стандартната библиотека (STL) в C++

1. Бързо сортиране (std::sort)

В състезателното програмиране почти винаги се налага да подредим данни, преди да ги обработваме. Вместо да пишем собствени алгоритми като Bubble Sort (които са бавни), C++ ни предоставя готова, силно оптимизирана функция — std::sort.

За да я използваме, трябва да включим библиотеката <algorithm>.

#include <iostream>
#include <vector>
#include <algorithm> // Необходима за std::sort

using namespace std;

int main() {
    // 1. Сортиране на обикновен масив
    int arr[] = {5, 2, 8, 1, 3};
    int n = 5;
    sort(arr, arr + n); // Сортира от началото до края
    
    // 2. Сортиране на вектор
    vector<int> vec = {5, 2, 8, 1, 3};
    sort(vec.begin(), vec.end());
    
    // 3. Сортиране в намаляващ ред
    sort(vec.begin(), vec.end(), greater<int>());
    
    return 0;
}

2. Сложност – понятие и оценка

Когато пишем код за състезания, програмата ни има времево ограничение (често 1 секунда). За 1 секунда компютърът прави около 108 операции. Сложността по време ни показва колко операции ще извърши алгоритъмът спрямо размера на входа (N).

СложностИмеПример
O(1)КонстантнаПроверка за четност. Времето не зависи от N.
O(log N)ЛогаритмичнаДвоично търсене. При N=1 000 000 прави макс 20 стъпки.
O(N)ЛинейнаОбхождане с един for цикъл.
O(N log N)Линейно-логаритмичнаstd::sort. При N=100 000 прави около 1 700 000 операции. Минава светкавично.
O(N²)КвадратичнаДва вложени цикъла. При N=100 000 прави 1010 операции -> TLE!

Златно правило:

Винаги проверявай ограниченията на задачата. Ако N ≤ 105, алгоритъм с O(N²) ще бъде бавен (Time Limit Exceeded). Трябва ти O(N log N) или O(N).

3. Двоично търсене (Binary Search)

Представи си играта "Намислих си число от 1 до 100". Ти казваш число, а аз отговарям "Нагоре" или "Надолу". Най-бързият начин да познаеш е винаги да цепиш интервала на две. Това е двоично търсене! За да работи, масивът задължително трябва да е сортиран.

vector<int> v = {10, 20, 30, 40, 50};
// binary_search връща true или false
bool exists = binary_search(v.begin(), v.end(), 30);

4. STL алгоритми: lower_bound и upper_bound

Често ни трябва да знаем къде се намира числото. Имаме две безценни функции (работят за O(log N)):

  • lower_bound(..., X): Връща итератор към първия елемент ≥ X.
  • upper_bound(..., X): Връща итератор към първия елемент > X.

За да вземем реалния индекс (от 0), изваждаме v.begin():

auto lb = lower_bound(v.begin(), v.end(), 30);
int index = lb - v.begin();

Хитър трик!

За да намерите колко пъти се среща дадено число в сортиран масив, просто извадете итераторите: Брой = upper_bound - lower_bound.
