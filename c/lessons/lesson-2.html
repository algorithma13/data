Побитови операции

1. Какво представляват?

Те работят директно с двоично представени данни (битовете на числата в паметта). Тъй като се изпълняват директно от процесора, те са изключително бързи.

Забележка: В този урок ще приемем, че работим с unsigned (беззнакови) числа, за да не усложняваме обясненията с битовете за знак при отрицателните числа.

2. Видове операции

Побитово отрицание ~X

Унарна операция. Преобразува всеки бит: 1 става 0, а 0 става 1.

Побитово ИЛИ X | Y

За всяка двойка битове: Резултатът е 1, ако поне един от битовете е 1.

Побитово И X & Y

За всяка двойка битове: Резултатът е 1, само ако и двата бита са 1.

Побитово изключващо ИЛИ (XOR) X ^ Y

За всяка двойка битове: Резултатът е 1, само ако двата бита са различни.

👉 Използвайте калкулатора вдясно, за да тествате операциите в реално време!

3. Практически приложения и оптимизации

Бърза проверка за четност

Вместо if (n % 2 == 0), което използва бавната операция деление, можем да проверим най-младшия бит (най-десния).

Ако (n & 1) == 0, числото е четно. Ако е 1, числото е нечетно.

Уникални свойства на XOR (^)

  • X ^ X = 0 (Всяко число XOR-нато със себе си дава 0).
  • X ^ 0 = X (Всяко число XOR-нато с 0 дава самото себе си).

4. Задача: Намиране на уникален елемент

Даден е масив, в който всички елементи се повтарят точно по два пъти, с изключение на един елемент. Намерете го.

Ако обходим масива и приложим XOR последователно на всички елементи, двойките еднакви числа ще се "нулират" (защото X^X=0). Накрая ще остане само уникалният елемент (защото X^0=X)!

int find_unique(vector<int>& nums) {
    int ans = 0;
    for(int n : nums) {
        ans ^= n; // същото като ans = ans ^ n;
    }
    return ans;
}

// Пример: {4, 1, 5, 2, 9, 1, 4, 2, 5} -> Отговор: 9
