Абстрактни типове и STL

Стандартната шаблонна библиотека (STL — Standard Template Library) в C++ ни предоставя готови, силно оптимизирани структури от данни (контейнери). Всяка структура поддържа определени операции много бързо, затова правилният избор на структура често решава задачата!

1. Типът Vector (Динамичен масив)

Представете си влак, на който можем да закачаме нови вагони в движение. Векторът (#include <vector>) е точно това – масив, който може автоматично да променя размера си. Използваме го, когато не знаем предварително колко елемента ще трябва да съхраним.

  • v.push_back(x): Добавя елемент x в края на вектора за амортизирано време O(1).
  • v.pop_back(): Премахва последния елемент за O(1).
  • v[i]: Директен достъп до елемент по индекс (от 0 до v.size() - 1) за O(1).
  • v.size() и v.empty(): Връщат текущия брой елементи и дали векторът е празен за O(1).
  • v.clear(): Изтрива всички елементи и прави размера 0.
#include <vector>
using namespace std;

vector<int> v;          // Празен вектор
v.push_back(10);        // [10]
v.push_back(25);        // [10, 25]
v.push_back(7);         // [10, 25, 7]
v[1] = 99;              // Променя индекса 1 -> [10, 99, 7]
v.pop_back();           // Премахва 7 -> [10, 99]

Важно за бързодействието!

Добавянето и премахването в края на вектора е светкавично — O(1). Но вмъкването или изтриването на елемент по средата (с v.insert() или v.erase()) изисква изместване на всички следващи елементи и отнема бавното O(N) време!

2. Итератори и съкратен цикъл

Итераторът е специален обект ("указател"), който сочи към конкретен елемент вътре в контейнера и ни позволява да се движим стъпка по стъпка през елементите.

  • v.begin(): Сочи към първия елемент (индекс 0).
  • v.end(): Сочи към позицията след последния елемент (служи за стопер на цикъла, не бива да се чете с *!).
  • *it: Достъпва стойността на елемента, към който сочи итераторът it.
vector<int> v = { 10, 20, 5, 30 };

// 1. Класическо обхождане с итератор (или с auto it = v.begin())
for(vector<int>::iterator it = v.begin(); it != v.end(); it++) {
    cout << *it << " ";
}

Модерният начин: Range-based for цикъл и auto

В C++11 и по-нови версии използваме ключовата дума auto (която сама познава типа) и съкратен цикъл:

for(int el : v) { cout << el << " "; } — чете копие на всеки елемент.

for(int &el : v) { el *= 2; } — с амперсанд (&) променяме директно самите елементи във вектора!

3. Стек (Stack)

Представете си купчина чинии. Можем да поставим нова чиния само най-отгоре и можем да вземем само най-горната чиния. Този принцип се нарича LIFO (Last-In, First-Out — Последен влязъл, първи излязъл). Включва се с #include <stack>.

  • s.push(x): Поставя елемент x най-отгоре за O(1).
  • s.pop(): Премахва най-горния елемент за O(1) (не връща стойността му!).
  • s.top(): Връща стойността на най-горния елемент за O(1) без да го маха.
#include <stack>
stack<int> s;
s.push(1);              // [1]
s.push(13);             // [1, 13] (13 е на върха)
cout << s.top();        // Отпечатва 13
s.pop();                // Премахва 13 -> остава [1]

Внимание за Runtime Error!

Никога не извиквайте s.top() или s.pop(), ако стекът е празен! Винаги проверявайте предварително с if (!s.empty()).

4. Опашка (Queue) и Двустранна опашка (Deque)

Опашката (#include <queue>) работи точно като опашка пред каса в магазин: първият наредил се клиент бива обслужен пръв. Това е принципът FIFO (First-In, First-Out — Първи влязъл, първи излязъл). Използва се масово при обхождане на графи в ширина (BFS).

  • q.push(x): Добавя елемент най-отзад на опашката — O(1).
  • q.pop(): Премахва първия елемент (най-отпред) — O(1).
  • q.front() и q.back(): Поглеждат съответно първия и последния елемент — O(1).

Бонус: Двустранна опашка (std::deque)

Структурата deque (Double-Ended Queue, #include <deque>) комбинира вектор, стек и опашка! Тя позволява бързо добавяне и триене за O(1) както отпред (push_front, pop_front), така и отзад (push_back, pop_back), плюс директен достъп по индекс d[i].

5. Приоритетна опашка (Priority Queue)

Представете си спешно отделение в болница: пациентите не влизат по реда на пристигане, а според приоритета (спешността) си. В C++ priority_queue (част от <queue>) е реализирана чрез двоична пирамида (Heap) и по подразбиране държи най-големия елемент най-отгоре (Max-Heap).

  • pq.push(x): Добавя елемент и го подрежда на правилното място за O(log N).
  • pq.pop(): Премахва най-големия елемент (от върха) за O(log N).
  • pq.top(): Връща най-големия елемент веднага за O(1).
#include <queue>

// 1. Стандартна приоритетна опашка (Max-Heap: най-големият е отгоре)
priority_queue<int> pq;
pq.push(10); pq.push(50); pq.push(20);
cout << pq.top(); // Извежда 50

// 2. Обратна приоритетна опашка (Min-Heap: най-малкият е отгоре)
priority_queue<int, vector<int>, greater<int>> min_pq;
min_pq.push(10); min_pq.push(50); min_pq.push(20);
cout << min_pq.top(); // Извежда 10

Състезателен трик: "Най-малките K елемента"

Ако търсим K-те най-малки числа в огромен поток от N числа, поддържаме стандартна Max-Heap с размер най-много K. При всяко ново число правим push(), и ако pq.size() > K, веднага правим pq.pop() (изхвърляме най-голямото до момента). Накрая в опашката остават точно K-те най-малки за време O(N log K)!
