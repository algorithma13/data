Трикове на езика С++

1. Къде създаваме масиви?

В състезателните задачи често се налага да работим с големи масиви (напр. 1 000 000 елемента). Ако декларирате такъв масив вътре във функция (например main), той се създава в паметта, наречена стек (stack).

Стекът има силно ограничен размер (обикновено няколко MB). Заделянето на голям масив там води до Stack Overflow (срив на програмата).
Решение: Декларирайте големите масиви глобално (извън всички функции). Те отиват в Хийп (Heap) паметта, която е ограничена само от общата ви RAM. 
// ПРАВИЛНО (Глобално деклариране)
int arr[1000001]; 
int main() { ... }

2. Бърз вход и изход

Стандартните cin и cout могат да бъдат бавни и да доведат до Time Limit Exceeded (TLE) при голям обем входни данни. Добавете тези три реда в началото на main: 

ios_base::sync_with_stdio(false);
cin.tie(NULL);
cout.tie(NULL);

Важно: Използвайте '\n' вместо endl. endl не само добавя нов ред, но и изпразва буфера на cout (flushing), което е много бавна операция.

3. Подаване по Референция (Указатели)

В С++ по подразбиране аргументите на функции се подават по стойност. Това означава, че се създава копие на обекта. При голям vector това е пагубно бавно.

Решение: Подавайте големи обекти по референция, като добавите & след типа на аргумента. Това не създава копие, а само псевдоним (прякор).

// БАВНО: Създава копие при всяко извикване
void by_value(vector<int> v) { ... }

// БЪРЗО: Подава се само "прякор" към оригинала
void by_ref(vector<int>& v) { ... }

👉 Тествайте симулатора вдясно, за да видите разликата!

4. Контейнери pair и tuple

Често се налага да групираме няколко стойности (напр. координати или тегло на ребро в граф).

  • pair<T1, T2> - достъпва се с .first и .second.
  • tuple<T1, T2, ...> - достъпва се с get<индекс>(името). 
vector<pair<int, int>> points;
points.push_back({1, 5}); // С++11 инициализация
sort(points.begin(), points.end()); // Сортира първо по X, после по Y

5. Съкращаване на дълги имена (using)

За да спестите време по време на състезание, използвайте using за създаване на псевдоними:

using ll = long long;
using vi = vector<int>;
using pii = pair<int, int>;
using vpii = vector<pii>;

// Сега можете да пишете:
vpii my_edges;
