Двоично търсене по отговора

1. Отвъд "класическото" търсене

Класическото двоично търсене намира елемент (или неговата позиция) в предварително сортиран масив. Но често се сблъскваме със задачи, при които търсим самия оптимален отговор. Вместо да проверяваме масив, ние правим двоично търсене в интервала от всички възможни отговори.

Ако търсим отговор X (например максимално разстояние между елементи), се питаме: "Можем ли да постигнем условието за отговор X?". Ако отговорът е ДА, опитваме с по-голям X. Ако е НЕ, опитваме с по-малък.

2. Монотонни редици и функция check()

Основа при двоичното търсене "по отговора" са монотонните редици от булеви стойности. Те изглеждат много просто: префикс от стойности false, последван от суфикс от true (при растящи функции) или обратното (при намаляващи).

Не пазим масива в паметта!

Не е нужно да имаме цялата редица от `true`/`false` изчислена предварително. Достатъчно е да можем да изчисляваме нейните членове "на момента", когато ни потрябват. За целта винаги пишем помощна функция bool check(int x).

bool check(int x) {
    // Тук разписваме логиката, която проверява 
    // дали стойността 'x' е валиден отговор за задачата.
    if (/* условието е изпълнено */) {
        return true;
    }
    return false;
}

3. Намиране на границата

Целта ни е да намерим точната "граница" между false и true. Поддържаме подинтервал [low, high], в който сме сигурни, че се намира границата.

  • В началото low и high са най-малката и най-голямата възможна стойност.
  • На всяка стъпка се грижим да е вярно check(low) == false и check(high) == true.
  • Ако low + 1 == high, търсенето приключва. Отговорът е в high (ако търсим първото true).
int low = MIN_VAL;
int high = MAX_VAL;

while (low + 1 < high) {
    int mid = low + (high - low) / 2;
    
    if (check(mid)) {
        high = mid; // Търсим първото срещане на true
    } else {
        low = mid;  // Все още сме в зоната на false
    }
}
// Отговорът е в 'high'

Сложността на този алгоритъм е O(log M × времето за функцията check), където M е броят на всички възможни отговори в първоначалния интервал.

4. Вариант с дробни числа (double)

Ако търсеният отговор може да бъде дробно число, интервалът става непрекъснат. Тогава не търсим точна граница, а приближение с допустима грешка (например 10-5). За целта въвеждаме константата EPS.

const double EPS = 0.00001;
double low = MIN_VAL;
double high = MAX_VAL;

while (high - low > EPS) { // Условието за край се променя
    double mid = (low + high) / 2.0;
    if (check(mid)) {
        high = mid;
    } else {
        low = mid;
    }
}
⚡ Симулатор: Търсене на границата
