Елементи на езика C++

Добре дошли в първия урок. Тук ще си припомним основните типове данни и ще разгледаме най-важните аритметични операции в състезателното програмиране.

1. Типове данни и операции

  • Цели числа: int (и long long за по-големи)
  • Дробни числа: float, double
  • Изчисления: Използвайте +, -, *, / и скоби () за аритметични операции.

2. Операция деление ( / )

Операцията деление, приложена между две целочислени променливи, дава цялата част от резултата на делението (отрязва дробната).

int a = 7, b = 3;
cout << a / b << endl; // ще отпечата 2

Ако поне една от променливите е дробна, резултатът е точен:

double a = 7, b = 3;
cout << a / b << endl; // ще отпечата 2.33333

3. Операция „остатък от деление“ ( % )

Използва се знакът % само между целочислени променливи или константи.

Например изразът 5 % 3 има стойност 2, защото 2 е остатъкът при делението на 5 с 3.

4. Отделяне на цифрите на цяло число

Това е един от най-често използваните алгоритми. Ако имаме числото n = 371234, можем да извлечем всяка негова цифра чрез комбинация от / и %:

  • единици: n % 10 (напр. 371234 % 10 = 4)
  • десетици: (n / 10) % 10 (371234 / 10 = 37123; 37123 % 10 = 3)
  • стотици: (n / 100) % 10
  • хиляди: (n / 1000) % 10
  • десетохиляди: (n / 10000) % 10

👉 Погледнете интерактивния панел вдясно, за да тествате как работи това за произволно число!

5. Знаков тип (char)

Променливите от тип char съхраняват един единствен символ в единични кавички.

char c = 'z';

Всеки символ има числов код (ASCII). Например 'A' има код 65. Можем да превръщаме между знак и числов код:

char a = 'A';
int n = (int)a; // n става 65

Много важен трик: Превръщане на символ-цифра в истинско число става чрез изваждане на кода на нулата ('0'):

char c = '7';
int i = c - '0'; // i става равно на числото 7

6. Разклоняване и условен оператор

Намиране на максимум от две числа:

// Вариант 1: с if-else
if (a > b) { 
    mx = a; 
} else { 
    mx = b; 
}

// Вариант 2: с вградена функция
mx = max(a, b);

7. Размяна на стойности (Swap)

Понякога е трудно да се възприеме, a = b; b = a; няма да осъществи размяната (тъй като първоначалната стойност на 'a' ще се загуби).

Правилният подход е с въвеждане на допълнителна временна променлива (често наричана t или temp):

int t = a;
a = b;
b = t;
