1. Същност и предназначение [cite: 15]

Какво е факторизация? [cite: 15]

Факторизация (или разлагане на прости множители) на едно естествено число n > 1 означава да го представим като произведение единствено от прости числа.[cite: 15]

Според Основната теорема на аритметиката, всяко естествено число n > 1 може да се разложи на прости множители по единствен начин (с точност до реда на множителите):[cite: 15]

n = p1k1 · p2k2 · … · pmkm [cite: 15]

където p1 < p2 < … < pm са прости числа, а k1, k2, …, km са техните степени (по колко пъти се среща съответният прост множител).[cite: 15]

Пример: Числото n = 360 се разлага като:
360 = 2 · 2 · 2 · 3 · 3 · 5 = 23 · 32 · 51[cite: 15]

Защо ни е необходима в състезателната информатика? [cite: 15]

В състезателните задачи рядко се иска само да се отпечатат простите делители.[cite: 15] Факторизацията е основен инструмент за решаване на задачи от теория на числата:[cite: 15]

  1. Намиране на броя на всички делители d(n): Ако n = p1k1 · p2k2 · … · pmkm, всеки делител на n се получава, като изберем степен за p1 (от 0 до k1, т.е. k1 + 1 възможности), степен за p2 (k2 + 1 възможности) и т.н.[cite: 15] Следователно:[cite: 15]
    d(n) = (k1 + 1)(k2 + 1)…(km + 1) [cite: 15]
    За 360 = 23 · 32 · 51 броят на всички делители е (3 + 1)(2 + 1)(1 + 1) = 4 · 3 · 2 = 24.[cite: 16]
  2. Проверка за точен квадрат или точен куб: Едно число е точен квадрат тогава и само тогава, когато всички степени ki в каноничното му разлагане са четни.[cite: 16]
  3. Намиране на НОД и НОК на много големи числа, както и решаване на задачи за делимост на произведения.[cite: 16]

Как съхраняваме резултата в C++? [cite: 16]

В зависимост от условието на задачата използваме един от следните два начина чрез динамичен масив (std::vector):[cite: 16]

  • Списък на всички прости множители с повторенията (vector<long long>) — използва се в първия примерен код (factor.cpp), където всеки прост множител се добавя в списъка толкова пъти, колкото дели числото.[cite: 1, 16] За n = 360 векторът ще съдържа 2 2 2 3 3 5.[cite: 16]
  • Списък от двойки {прост_делител, степен} (vector<pair<long long, int>>) — използва се във втория примерен код (weel.cpp), където за всеки прост делител се пази неговата стойност и колко пъти се среща.[cite: 2, 16] За n = 360 векторът ще съдържа двойките {2, 3}, {3, 2}, {5, 1}, което позволява извеждане във вида 360 = 2^3 * 3^2 * 5^1.[cite: 2, 16]

2. Оптимизации на пробното деление [cite: 16]

Нека проследим как бавната проверка на всички числа се оптимизира до бързо състезателно решение.[cite: 16]

Защо проверката до n е твърде бавна? [cite: 16]

Ако проверяваме последователно всички делители от 2 до n, при вход n = 1012 (което напълно се побира в типа long long) програмата ще извърши 1012 операции.[cite: 17] Един съвременен процесор в тестова система прави около 108 операции в секунда, така че такъв алгоритъм със сложност O(n) ще надвиши лимита за време (Time Limit Exceeded – TLE).[cite: 17]

Оптимизация 1: Проверка само до √n и динамично намаляване на n (factor.cpp) [cite: 17]

Математическо свойство: Ако едно число n е съставно, то може да се представи като произведение n = a · b, където 1 < a ≤ b < n.[cite: 17] Ако допуснем, че и двата множителя са по-големи от √n, тогава произведението им ще бъде a · b > √n · √n = n, което е невъзможно.[cite: 17] Следователно всяко съставно число n има поне един прост делител, по-малък или равен на √n.[cite: 17]

Пример 1: Класическа оптимизирана факторизация (factor.cpp) [cite: 1, 17]

#include <iostream>
#include <vector>
using namespace std;

vector<long long> factorize(long long n)
{
    vector<long long> factors;
    for(long long i = 2; i * i <= n; i++)
    {
        while(n % i == 0)
        {
            factors.push_back(i);
            n /= i;
        }
    }

    // Ако след цикъла е останало число > 1, то е последният прост делител
    if(n > 1) factors.push_back(n);
    return factors;
}

int main()
{
    long long n; cin >> n;
    vector<long long> result = factorize(n);
    for(long long f : result)
    {
        cout << f << " ";
    }
    cout << "\n";
}
[cite: 1, 17, 18]

Подробен разбор на кода в factor.cpp: [cite: 18]

  1. Условие на цикъла for(long long i = 2; i * i <= n; i++): Вместо да изчисляваме корен квадратен, проверяваме дали i * i <= n.[cite: 1, 18] Тъй като типът на i е long long, умножението i * i няма да препълни при n ≤ 1018.[cite: 18] Освен това при всяко деление n /= i стойността на n намалява, с което автоматично намалява и горната граница на цикъла.[cite: 1, 18]
  2. Защо във вектора factors попадат само прости числа? Във вътрешния цикъл while(n % i == 0) делим n на i, докато се дели без остатък.[cite: 1, 18] Така, преди i да достигне съставно число като 4, 6, 8, 9…, от n вече са премахнати всички негови по-малки прости множители (2, 3 и т.н.).[cite: 18, 19] Затова за съставно i условието n % i == 0 никога няма да бъде вярно.[cite: 19]
  3. Защо е необходима проверката if(n > 1) factors.push_back(n);? Ако след приключване на цикъла i * i <= n числото n все още е по-голямо от 1, то няма нито един делител ≤ √n, което означава, че останалото n е просто число и е последният прост множител.[cite: 1, 19]

Трасировка на factor.cpp при вход n = 140: [cite: 19]

  • Начало: n = 140, factors = {}.[cite: 19]
  • i = 2: 2 * 2 <= 140 (вярно).[cite: 19] Влизаме в while(n % 2 == 0):[cite: 19]
    • 140 се дели на 2 → добавяме 2 във factors, n става 70.[cite: 19]
    • 70 се дели на 2 → добавяме 2 във factors, n става 35.[cite: 19]
  • i = 3: 3 * 3 <= 35 (9 ≤ 35, вярно), но 35 mod 3 ≠ 0.[cite: 19]
  • i = 4: 4 * 4 <= 35 (16 ≤ 35, вярно), но 35 mod 4 ≠ 0.[cite: 19]
  • i = 5: 5 * 5 <= 35 (25 ≤ 35, вярно).[cite: 19] 35 се дели на 5 → добавяме 5 във factors, n става 7.[cite: 19]
  • i = 6: Проверяваме 6 * 6 <= 7 (36 ≤ 7 — невярно).[cite: 19] Цикълът приключва веднага![cite: 19]
  • След цикъла: Проверяваме if(n > 1) — тъй като n = 7 > 1, добавяме 7 във factors.[cite: 19]
  • Изход: Във функцията main() цикълът for(long long f : result) отпечатва: 2 2 5 7.[cite: 1, 20]

Оптимизация 2: Колесна факторизация за делителите 2 и 3 (weel.cpp) [cite: 20]

В factor.cpp цикълът проверява всяко поредно число i (2, 3, 4, 5, 6, 7, 8, 9…), въпреки че знаем, че четните числа над 2 и кратните на 3 над 3 няма как да са прости.[cite: 20]

Можем да ускорим алгоритъма 3 пъти, като разгледаме остатъците на естествените числа при деление на 6:[cite: 20]

  • 6k — дели се на 6 (и на 2, и на 3)[cite: 20]
  • 6k + 1 — не се дели нито на 2, нито на 3[cite: 20]
  • 6k + 2 = 2(3k + 1) — четно число (дели се на 2)[cite: 20]
  • 6k + 3 = 3(2k + 1) — дели се на 3[cite: 20]
  • 6k + 4 = 2(3k + 2) — четно число (дели се на 2)[cite: 20]
  • 6k + 5 (което е същото като 6(k + 1) - 1) — не се дели нито на 2, нито на 3[cite: 20]

Следователно всички прости числа, по-големи от 3, са от вида 6k - 1 и 6k + 1.[cite: 20] Ако ги запишем подред, като започнем от 5, получаваме редицата:[cite: 20]

5, 7, 11, 13, 17, 19, 23, 25, 29, 31 … [cite: 20]

Забележете как се променя стъпката между съседните числа:[cite: 20]

5 →+2 7 →+4 11 →+2 13 →+4 17 →+2 19 … [cite: 21]

Ако първо проверим отделно делителите 2 и 3, след това от i = 5 нататък можем просто да редуваме стъпка +2 и +4![cite: 2, 21] По този начин проверяваме само 2 от всеки 6 последователни числа и прескачаме 2/3 от ненужните проверки.[cite: 21]

Пример 2: Колесна факторизация с двойки {делител, степен} (weel.cpp) [cite: 2, 21]

#include <iostream>
#include <vector>
#include <utility>
using namespace std;

// Връща вектор от двойки: {прост_делител, степен}
vector<pair<long long, int>> factorize(long long n)
{
    vector<pair<long long, int>> factors;

    // 1. Обработваме делителите 2 и 3 поотделно
    for(long long d : {2, 3})
    {
       if(n % d == 0)
       {
           int cnt = 0;
           while(n % d == 0)
           {
               n /= d;
               cnt++;
           }
           factors.push_back({d, cnt});
       }
    }

    // 2. Проверяваме само числа от вида 6k - 1 и 6k + 1 (редуваме стъпка +2 и +4)
    long long step = 2;
    for (long long i = 5; i * i <= n; i += step, step = 6 - step)
    {
        if(n % i == 0)
        {
            int br = 0;
            while(n % i == 0)
            {
                n /= i;
                br++;
            }
            factors.push_back({i, br});
        }
    }

    // 3. Останал прост делител > sqrt(n)
    if(n > 1) factors.push_back({n, 1});
    return factors;
}

int main()
{
    long long n; cin >> n;
    auto res = factorize(n);

    cout << n << " = ";
    for(int i = 0; i < res.size(); i++)
    {
        cout << res[i].first << "^" << res[i].second;
        if(i + 1 < res.size()) cout << " * ";
    }
    cout << "\n";
}
[cite: 2, 21, 22, 23]

Подробен разбор на кода в weel.cpp: [cite: 23]

  1. Библиотека <utility> и тип pair<long long, int>: Всеки елемент на вектора factors е двойка (pair), в която първото поле (.first от тип long long) пази самия прост делител, а второто поле (.second от тип int) пази неговата степен.[cite: 2, 23]
  2. Етап 1 — Обработка на делителите 2 и 3 (for(long long d : {2, 3})): Променливата d приема първо стойност 2, а след това 3.[cite: 2, 23] Ако n се дели на d, броячът cnt преброява колко пъти d се съдържа в n чрез цикъла while(n % d == 0), след което двойката {d, cnt} се записва във вектора factors.[cite: 2, 23]
  3. Етап 2 — Как работи i += step, step = 6 - step:[cite: 2, 23]
    • В началото задаваме long long step = 2; и i = 5.[cite: 2, 23]
    • В края на първата итерация (i = 5): към i се прибавя step (5 + 2 = 7), а веднага след това step става 6 - 2 = 4.[cite: 23]
    • В края на втората итерация (i = 7): към i се прибавя новата стойност на step (7 + 4 = 11), а step става 6 - 4 = 2.[cite: 24]
    • Така без нито една условна конструкция if стъпката автоматично се редува: 2, 4, 2, 4, 2, 4…[cite: 24]
    • Когато намерим делител i, променливата br преброява неговата степен и добавяме {i, br} във factors.[cite: 2, 24]
  4. Етап 3 — Останал прост делител (if(n > 1)): Ако след цикъла е останало число n > 1, то със сигурност е просто число на първа степен, затова добавяме {n, 1}.[cite: 2, 24]
  5. Форматирано извеждане в main(): Чрез res[i].first << "^" << res[i].second отпечатваме всеки прост множител и неговата степен, а условието if(i + 1 < res.size()) cout << " * "; поставя знака за умножение между тях, без да слага излишен знак след последния множител.[cite: 2, 24]

Трасировка на weel.cpp при вход n = 360: [cite: 24]

  • Етап 1 (d = 2): 360 се дели на 2 три пъти (360 → 180 → 90 → 45).[cite: 24] Записваме {2, 3} във factors, n става 45.[cite: 24]
  • Етап 1 (d = 3): 45 се дели на 3 два пъти (45 → 15 → 5).[cite: 24] Записваме {3, 2} във factors, n става 5.[cite: 24]
  • Етап 2 (i = 5): Проверяваме 5 * 5 <= 5 (25 ≤ 5 — невярно).[cite: 24] Основният цикъл изобщо не се изпълнява![cite: 24]
  • Етап 3 (if(n > 1)): Тъй като n = 5 > 1, записваме {5, 1} във factors.[cite: 24]
  • Изход на екрана: 360 = 2^3 * 3^2 * 5^1.[cite: 25]

Интерактивен скенер: Какво е факторизация?

Въведете естествено число n > 1, за да видите разлагането му по Основната теорема на аритметиката и как се пази в паметта на C++.

Намиране на броя на всички делители d(n)

Всеки делител се образува чрез избор на степен от 0 до ki за всеки прост множител: d(n) = (k1 + 1)(k2 + 1)…(km + 1).

Проверка за точен квадрат или точен куб

Едно число е точен квадрат, ако всички степени ki са четни, и точен куб, ако всички степени ki се делят на 3.

НОД, НОК и делимост на произведения чрез факторизация

За НОД вземаме минималната степен min(ai, bi), а за НОК — максималната степен max(ai, bi) за всеки прост делител.

5. Задача 1: „Брой на всички делители“ (с weel.cpp)

Чрез степените на простите делители (res[i].second) пресмятаме общия брой делители по формулата (k1 + 1)(k2 + 1)…(km + 1).

// Решение на Задача 1 в main() чрез функцията factorize(n) от weel.cpp:
int main()
{
    long long n; cin >> n;
    auto res = factorize(n);
    long long total_divisors = 1;
    for(int i = 0; i < res.size(); i++)
    {
        total_divisors *= (res[i].second + 1);
    }
    cout << total_divisors << "\n";
}

7. Задача 3: „Допълване до точен квадрат“ (с weel.cpp)

Намираме най-малкото естествено число m, така че n · m да стане точен квадрат (умножаваме всички res[i].first с нечетна степен res[i].second).

// Решение на Задача 3 в main() чрез функцията factorize(n) от weel.cpp:
int main()
{
    long long n; cin >> n;
    auto res = factorize(n);
    long long m = 1;
    for(int i = 0; i < res.size(); i++)
    {
        if(res[i].second % 2 != 0)
        {
            m *= res[i].first;
        }
    }
    cout << m << "\n";
}
