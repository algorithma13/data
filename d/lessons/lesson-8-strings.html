1. Какво е низ (std::string) и въвеждане

В C++ типът string (от библиотеката <string>) представлява динамична редица от символи (char). За разлика от обикновените масиви, низовете могат автоматично да променят дължината си.

  • cin >> s; — чете само една дума (спира при първия интервал, табулация или нов ред).
  • getline(cin, s); — чете целия ред заедно с интервалите до знака за нов ред '\n'.

⚠️ Важен капан на състезания: cin >> n преди getline()!

Когато четете число с cin >> n;, символът за нов ред (Enter) остава във входния буфер. Ако веднага след това извикате getline(cin, s);, то ще прочете празен низ! Решението е да изчистите буфера с cin.ignore(); (или cin >> ws;) преди getline.

int n;
string line;
cin >> n;
cin.ignore();       // Изчиства останалия Enter след числото n!
getline(cin, line); // Вече чете коректно целия ред с интервали

2. Долепяне (Конкатенация), дължина и сравнение

Низовете могат да се слепват чрез оператора + или +=, а дължината им се взима с s.size() или s.length() (работят за време O(1)).

🚀 Оптимизация за 100 точки: s += c срещу s = s + c

В цикъл винаги използвайте s += c; или s.push_back(c); (сложност O(1)), вместо s = s + c;, което копира целия низ наново на всяка стъпка (сложност O(N)) и води до Time Limit Exceeded при дълги низове!

Лексикографско сравнение: Операторите ==, !=, <, > сравняват низовете точно както в речник (символ по символ според техния ASCII код). Например "Apple" < "Banana" е true.

3. Индексиране, ASCII аритметика и Честотен масив

Индексите на символите започват от 0 до s.size() - 1. Всеки символ от тип char всъщност се пази в паметта като своето число от ASCII таблицата:

  • Цифрите '0'..'9' имат кодове от 48 до 57 → int d = c - '0'; превръща символ-цифра в число!
  • Главните букви 'A'..'Z' имат кодове от 65 до 90.
  • Малките букви 'a'..'z' имат кодове от 97 до 122 → c - 'a' дава поредния номер на буквата от 0 до 25.

Полезни функции от <cctype> и Честотен масив

vector<int> br(26, 0);
for (char c : s) {
    if (isalpha(c)) {          // Проверява дали c е буква
        c = tolower(c);        // Прави буквата малка ('A' -> 'a')
        br[c - 'a']++;         // Увеличава брояча за тази буква
    }
}

5. Преобразуване (Число ↔ Низ) и <algorithm>

Често се налага да превърнем цяло число в низ (за да му преброим или разменим цифрите) или обратното:

  • string s = to_string(2026); — превръща число от тип int или long long в "2026".
  • int x = stoi("450"); — превръща низ в int.
  • long long y = stoll("9876543210"); — превръща низ в 64-битов long long.

Също така функциите от <algorithm> работят директно върху низове:

reverse(s.begin(), s.end()); // Обръща низа наобратно за O(N)
sort(s.begin(), s.end());    // Сортира символите по ASCII ред за O(N log N)

6. Приложни състезателни задачи с низове

Разгледайте четирите фундаментални алгоритмични шаблона, които се срещат постоянно в задачите за Група D, и ги трасирайте стъпка по стъпка в десния панел:

Задача А: Проверка за Палиндром с два указателя O(N) време | O(1) памет

Два индекса L = 0 и R = s.size() - 1 се движат един срещу друг. Ако навсякъде s[L] == s[R], думата е палиндром.

Задача Б: Компресия на низ (Run-Length Encoding - RLE) O(N) време

Заменяме всяка поредица от еднакви съседни символи с броя им и самия символ: например "aaabbc" се компресира до "3a2b1c".

Задача В: Извличане и сумиране на цели числа от текст O(N) време

В низ като "a12b305c4" откриваме многоцифрените числа (12, 305 и 4) чрез натрупване cur = cur * 10 + (c - '0') и намираме сумата им (321).
