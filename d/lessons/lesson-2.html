Техники на програмирането

1. Съставни логически условия

В програмирането често трябва да проверяваме повече от едно условие едновременно. Използваме следните оператори:

  • Логическо И (&&): (A) && (B) е вярно само ако И двете условия са верни. Използва се за проверка дали число принадлежи на интервал: (a <= x) && (x <= b).
  • Логическо ИЛИ (||): (A) || (B) е вярно ако ПОНЕ ЕДНО от условията е вярно. Използва се за проверка дали число е извън интервал: (x < a) || (x > b).
  • Логическо отрицание (!): !(A) обръща стойността. Ако A е вярно, става грешно и обратното.

👉 Тествайте логическите гейтове във визуализатора вдясно!

2. Цикли (Повтарящи се действия)

Когато искаме да повторим част от кода многократно, използваме цикли. Най-често използваният е for цикълът.

// Отпечатва числата от 1 до 100
for(int i = 1; i <= 100; i++) {
    cout << i << endl;
}

Можем да вложим един цикъл в друг (например за отпечатване на таблицата за умножение). Други видове цикли са while (цикъл с пред-условие) и do-while (с пост-условие).

// Цикъл, който чете числа до въвеждане на 0 (сигнал за край)
int a = 1, s = 0;
while (a != 0) {
    cin >> a;
    s += a;
}

3. Функции в C++

Функциите ни позволяват да групираме код, който ползваме често, за да не го пишем многократно.

// Дефиниране на функция, която връща по-голямото от две числа
int max2(int a, int b) {
    if (a > b) return a;
    return b;
}

// Извикване
int m = max2(5, 10); // m ще получи стойност 10

4. Едномерни масиви

Масивът е последователност от еднотипни променливи, подредени в паметта една след друга.

Много важно: В С++ индексацията на масивите започва от 0. Ако обявим int a[10];, валидните индекси са от 0 до 9. Достъпването на a[10] е груба грешка!

Запълване на масив от клавиатурата:

int a[10];
for (int i = 0; i < 10; i++) {
    cin >> a[i];
}

Намиране на максимум и минимум в масив

Това е един от най-важните алгоритми. За да го направим безопасно, задаваме на началния максимум много малка стойност (напр. -1000000), а на минимума - много голяма. След това обхождаме масива.

const int MAX_VAL = 1e6;
int maxv = -MAX_VAL; 
int minv = MAX_VAL;

for (int i = 0; i < n; i++) {
    if (a[i] > maxv) {
        maxv = a[i]; // Намерихме нов максимум
    }
    if (a[i] < minv) {
        minv = a[i]; // Намерихме нов минимум
    }
}
