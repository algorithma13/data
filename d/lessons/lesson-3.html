Структури от данни: Вектори

1. Типът vector

На вектора можем да гледаме като на масив, размерът на който може да се изменя динамично по време на изпълнението на програмата.

Използваме го, когато не можем да си позволим да заделим статичен масив с максималния възможен брой елементи (например, защото не знаем този брой предварително).

#include <iostream>
#include <vector> // Задължителна библиотека
using namespace std;

2. Деклариране на вектор

Общата форма е vector<тип> име;. Векторите могат да се декларират празни, или с определен начален капацитет и стойности по подразбиране.

// Празен вектор
vector<int> v; 

// Вектор с начален капацитет 10 (попълнен с нули)
vector<int> v1(10); 

// Вектор с капацитет 5 и стойности по подразбиране 10
vector<int> v2(5, 10); 

// Инициализация със списък (C++11)
vector<int> v3{342, 42, 432};

3. Основни операции

  • Добавяне: v.push_back(X); добавя елемента X в края на вектора. Размерът му се увеличава с 1.
  • Премахване: v.pop_back(); премахва последния елемент от вектора.
  • Достъп: Както при масивите v[i] или по-сигурния метод v.at(i) (хвърля грешка, ако индексът е извън граници).

👉 Тествайте динамичното добавяне и премахване на елементи във визуализатора вдясно!

4. Векторни функции

  • v.size() - връща текущия брой на елементите във вектора.
  • v.empty() - връща true(1), ако векторът е празен, и false(0) в противен случай.
  • v.clear() - премахва всички елементи от вектора.
  • v.front() и v.back() - връщат съответно първия и последния елемент.

5. Обхождане (Итерация)

Можем да обходим вектор със стандартен for цикъл чрез индекси:

for (int i = 0; i < v.size(); i++) {
    cout << v[i] << " ";
}

Или чрез модерния С++11 range-based for цикъл. Използваме референция (&), за да не копираме елементите излишно.

// Само за четене (по-бързо и безопасно)
for (const auto& value : v) {
    cout << value << " ";
}

// Ако искаме да променим стойностите в самия вектор
for (auto& value : v) {
    value *= 2; 
}

6. Сортиране на вектор

За да сортираме вектор, използваме функцията sort от библиотеката <algorithm>. Подаваме й итератори към началото и края.

#include <algorithm>
// ...
vector<int> v{ 342, 42, 432 };
sort(v.begin(), v.end()); 
// Резултат: 42 342 432
Интерактивен std::vector

Добавяйте, премахвайте и сортирайте елементи, за да видите как векторът динамично променя размера си (v.size()).

v.size() = 0 | v.empty() = true
