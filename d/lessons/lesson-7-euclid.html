Алгоритъм на Евклид – намиране на НОД

НОД: Математика срещу информатика

  • В математиката НОД(24, 36) – разлагаме на прости множители.
  • В състезателната информатика числата рядко са малки.
  • Ако пуснем обикновен цикъл, който проверява от 1 до по-малкото от двете, при вход 1018 програмата ни ще получи TLE.
  • За да решим задачата за части от милисекундата, използваме един от най-старите и гениални алгоритми в историята – Алгоритъм на Евклид.

Идеята на Евклид

НОД на две числа не се променя, ако от по-голямото извадим по-малкото:

НОД(A, B) = НОД(A − B, B)
Капанът:
Търсим НОД(1018, 1).
Ако използваме изваждане ще трябва да извадим единицата 1018 пъти.
Сигурен TLE.

Най-бързият вариант: Евклид с деление по модул (%)

Евклид с деление по модул

Вместо да изваждаме B от A многократно, можем наведнъж да махнем всички възможни пъти, в които B се съдържа в A.

Какво остава след това?

Точно остатъкът при деление на A на B.

Основната формула на бързия алгоритъм на Евклид е:

НОД(a, b) = НОД(b, a mod b)

Този процес се повтаря, докато остатъкът стане 0. Тогава другото число е търсеният НОД:

НОД(a, 0) = a

Пример: НОД(1071, 462)

  • НОД(1071, 462) → 1071 % 462 = 147 → преминаваме към НОД(462, 147)
  • НОД(462, 147) → 462 % 147 = 21 → преминаваме към НОД(147, 21)
  • НОД(147, 21) → 147 % 21 = 0 → преминаваме към НОД(21, 0)
  • Второто число е 0, спираме! Отговор: 21

Реализация

  • Не се налага да проверяваме кое от двете числа е по-голямо в началото.
  • Ако a < b, още на първата стъпка операцията a % b ще е равна на a и алгоритъмът автоматично ще размени местата им.

GCD: Итеративен алгоритъм

long long gcd_it(long long a, long long b)
{
    while(b != 0)
    {
        long long r = a % b;
        a = b;
        b = r;
    }
    return a;
}
int main()
{
    long long a, b;
    cin >> a >> b;
    cout << gcd_it(a, b) << "\n";
}

Вградената функция __gcd

  • Съществува вградена функция за намиране на НОД, която се нарича __gcd(a, b).
  • Внимание: Името започва с две долни черти.

Пример с __gcd

int main()
{
    long long a, b;
    cin >> a >> b;
    cout << __gcd(a, b) << "\n";

    long long c; cin >> c;
    cout << __gcd(__gcd(a, b), c) << "\n";
}

Плюсове и минуси на вградената функция __gcd

Плюсове Минуси
Пести време за писане Шаблонна функция: ако напишете __gcd(a, b), където a е int, а b е long long, програмата няма да се компилира. Двете променливи трябва да са от абсолютно един и същ тип.
Нулев шанс за техническа грешка. Проблем при отрицателни числа: Ако подадете отрицателно число, функцията може да върне отрицателен резултат, докато математически НОД е винаги положително число. Винаги слагайте abs(), ако входът може да е отрицателен.

Приложение 1: Намиране на НОК

  • От математиката: НОК(a, b) = (a . b) / НОД(a, b)
  • Уловка: Ако a = 1010 и b = 1010, произведението a * b става 1020, което препълва long long.
  • Трик: Първо делим на НОД, а след това умножаваме
long long lcm(long long a, long long b)
{
    if (a == 0 || b == 0) return 0;
    return (a / __gcd(a, b)) * b;
}

Приложение 2: Съкращаване на обикновени дроби

  • В много задачи трябва да съберем две дроби a/b + c/d и да изведем резултата като несъкратима дроб.
  • За да стане дробта числител/знаменател несъкратима, просто делим и числителя, и знаменателя на техния НОД.
long long num = 24, den = 36; // Дробта 24/36
long long g = __gcd(abs(num), abs(den));
num /= g; // става 2
den /= g; // става 3
// Резултат: 2/3

Приложение 3: НОД на масив от числа

Имаме редица от N числа [ a1, a2, …, aN ] и търсим най-големия общ делител на всички тях:

long long ans = a[1];
for (int i = 2; i <= n; i++)
{
    ans = __gcd(ans, a[i]);
    if (ans == 1) break; // Оптимизация: НОД не може да стане по-малък от 1!
}

Приложение 4: Целочислени точки върху отсечка

  • Дадена е координатна система и отсечка с краища в точки с цели координати A(x1, y1) и B(x2, y2).
  • Въпрос: Колко точки с точни координати лежат точно върху отсечката AB (включително краищата)?
  • Вместо да проверяваме точки с цикли, отговорът се намира директно чрез Евклид:
Брой точки = НОД(|x1 − x2|, |y1 − y2|) + 1
long long points_on_seg(long long x1, long long y1, long long x2, long long y2)
{
    return __gcd(abs(x1 - x2), abs(y1 - y2)) + 1;
}
⚡ Акцент 1: Постъпкова визуализация на НОД(A, B) Стъпка 0

Проследете как на всяка стъпка намираме частното q = a / b и остатъка r = a % b от равенството a = b · q + r, след което преминаваме към НОД(b, r).
