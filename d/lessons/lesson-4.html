Математика: Цели числа и алгоритми

1. Целочислени типове данни и препълване (Overflow)

Изборът на правилния тип е ключов, за да избегнете грешки, наречени препълване (overflow), когато резултатът от изчисление надхвърли капацитета на типа в паметта:

  • int: Най-често използваният тип. Побира числа от около -2 · 109 до 2 · 109.
  • long long: Най-добрият ви приятел в състезателното програмиране! Може да съхранява числа от -9 · 1018 до 9 · 1018.
  • unsigned long long: Само за положителни числа.

Внимание: Опасност от препълване!

Умножението на два int-a може лесно да доведе до препълване. Ако умножавате две числа, които са около 105, резултатът ще бъде 1010, което не се побира в int и ще доведе до грешен резултат (отрязан или отрицателен). 👉 Вижте симулатора вдясно!

Съвет: Винаги използвайте long long за променливи в състезателни задачи, освен ако не сте напълно сигурни, че int е достатъчен.

2. Остатък при деление (Модул, %) и отрицателни числа

При отрицателни числа знакът на резултата от a % m в C++ е същият като знака на делимото a. Например: -10 % 3 е -1.

За да получите винаги положителен остатък (математически коректен), използвайте следната формула:

int result = (a % m + m) % m;

3. Задача: Сума на цифрите на число

Да се напише програма, която намира сумата на цифрите на дадено положително цяло число N.

Алгоритъм: Извличаме последната цифра с операцията % 10. Добавяме я към сумата. След това я премахваме от числото чрез целочислено деление / 10. Повтаряме, докато числото стане 0.

long long n;
cin >> n;
int sum = 0;

while (n > 0) {
    sum += n % 10;
    n /= 10;
}
cout << sum << endl;

👉 Пуснете аниматора вдясно, за да видите стъпките!

4. Задача: Броене на четни и нечетни

Дадени са n на брой цели числа. Пребройте колко от тях са четни и колко са нечетни.

int n; 
cin >> n;
int even = 0, odd = 0;

for(int i = 0; i < n; i++) {
    int num; 
    cin >> num;
    if(num % 2 == 0) {
        even++;
    } else {
        odd++;
    }
}
cout << even << endl;
cout << odd << endl;
