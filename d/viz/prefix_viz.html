Визуализация: Префиксни суми

Подготовка: Въведете стойности за базовия масив (напр. цени на стоки) и заявки за суми в интервал (от индекс L до индекс R). След това стартирайте визуализацията, за да проследите как работи алгоритъмът стъпка по стъпка.

Код на алгоритъма (C++)

#include <bits/stdc++.h> using namespace std; const int MAXN = 100005; long long a[MAXN]; long long prefix[MAXN]; int main() { int n, q; cin >> n >> q; for(int i = 1; i <= n; i++) { cin >> a[i]; prefix[i] = prefix[i-1] + a[i]; } for(int i = 0; i < q; i++) { int L, R; cin >> L >> R; // L и R са 1-базирани cout << prefix[R] - prefix[L-1] << "\n"; } }

Памет: Масиви (1-базирани)

Легенда: [Сиво: Глобална нула] | [Жълто: Текущ запис] | [Зелено: Четене при запис] | [Светлосиньо: prefix[R]] | [Червено: prefix[L-1]]

Състояние на променливите

Индекс (i) a[i] / prefix[i] L (Начало) R (Край)
- - - -
💡 Ключов момент: Глобалните масиви (ред 4-6) се инициализират с нули. Затова prefix[0] = 0, което предотвратява грешки при заявка с L = 1.
