Решение D4: Броене на породи

Школа МГ
Тема: Префиксни суми
C++ Оптимално Решение

Това е пълното решение, което отговаря на заявките за време O(1) и минава всички тестове. Поддържат се три отделни глобални масива за всяка от трите породи крави.

#include <iostream> using namespace std; const int MAXN = 100005; int pref1[MAXN]; int pref2[MAXN]; int pref3[MAXN]; int main() { ios_base::sync_with_stdio(false); cin.tie(NULL); int n, q; cin >> n >> q; for(int i = 1; i <= n; i++) { int curr; cin >> curr; pref1[i] = pref1[i - 1]; pref2[i] = pref2[i - 1]; pref3[i] = pref3[i - 1]; pref1[i] += (curr == 1); pref2[i] += (curr == 2); pref3[i] += (curr == 3); } for(int i = 0; i < q; i++) { int a, b; cin >> a >> b; cout << (pref1[b] - pref1[a - 1]) << " " << (pref2[b] - pref2[a - 1]) << " " << (pref3[b] - pref3[a - 1]) << "\n"; } }
⚡ Симулатор на решението
Подготовка: Въведете номера на породи (1, 2, 3) и заявки, след което стартирайте симулацията.
