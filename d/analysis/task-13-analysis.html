ЗАДАЧА D13: Анализ
Проследяване на контакти (Cowntact Tracing)

⚡ Метод: Пълно изчерпване (Brute Force)
⏱️ Сложност: O(N · T²) време | O(N + T) памет

Анализ на задачата

Подход: Симулация с пълно изчерпване
Тъй като ограниченията на задачата са много малки (N ≤ 100, T ≤ 250), можем да приложим пълно изчерпване (Brute force) на всички възможни хипотези за това коя крава е "нулев пациент" и какъв е лимитът K. За всяка хипотеза (комбинация от предполагаем нулев пациент P и лимит K) извършваме симулация на всички контакти по хронологичен ред. Ако след симулацията полученото състояние на всички крави съвпада с финалния низ target, хипотезата е валидна.

Избор на граници за K: Една крава не може да предаде заразата повече пъти от общия брой взаимодействия T. Следователно е достатъчно да тестваме всички стойности на K от 0 до T + 1. Стойността T + 1 практически представлява "безкрайност" (няма горна граница).

Сложност

  • По време: Сортирането на контактите отнема O(T log T). Основната част на алгоритъма се състои от три вложени цикъла: O(N) за избор на пациент, O(T) за избор на K и O(T) за самата симулация. Общата сложност е O(N · T²). При N ≤ 100 и T ≤ 250, извършваме около 100 · 250² = 6 250 000 операции, което без проблем се изпълнява в рамките на 2.0 секунди.
  • По памет: O(T) за съхраняване на контактите и O(N) за стринговете и масивите в симулацията. Изключително малко спрямо лимита от 256 MB.

Псевдокод на основната логика

// 1. Сортиране на контактите по време t възходящо
SORT(shakes.begin(), shakes.end(), cmp_by_t);

int possible_patients = 0;
int min_k = 1000, max_k = -1;

// 2. Външен цикъл: избор на потенциален нулев пациент P
FOR P FROM 0 TO N - 1:
    IF target[P] == '0': CONTINUE; // Здрава крава не може да е източник

    bool valid_patient = FALSE;

    // 3. Среден цикъл: избор на лимит на предаване K
    FOR K FROM 0 TO T + 1:
        state = НИЗ ОТ N НУЛИ
        shakes_count = МАСИВ ОТ N НУЛИ
        state[P] = '1' // заразяваме нулевия пациент

        // 4. Вътрешен цикъл: хронологична симулация на контактите
        FOR EACH shake IN shakes:
            int u = shake.x, v = shake.y
            bool u_sick = (state[u] == '1')
            bool v_sick = (state[v] == '1')

            IF u_sick:
                shakes_count[u]++
                IF shakes_count[u] <= K: state[v] = '1'
            IF v_sick:
                shakes_count[v]++
                IF shakes_count[v] <= K: state[u] = '1'

        // 5. Проверка дали симулацията е успешна
        IF state == target:
            valid_patient = TRUE
            min_k = MIN(min_k, K)
            max_k = MAX(max_k, K)

    IF valid_patient: possible_patients++

// 6. Оформяне на резултата
PRINT possible_patients, min_k
IF max_k == T + 1: PRINT "Infinity"
ELSE: PRINT max_k
