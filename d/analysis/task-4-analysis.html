Анализ D4: Броене на породи

Школа МГ
Тема: Префиксни суми

За да решим задачата оптимално и да избегнем Time Limit Exceeded, използваме техниката с префиксни суми, но я адаптираме за 3 отделни породи.

1. Дефинираме три глобални едномерни префиксни масива.
Глобалните масиви автоматично се запълват с 0, което ни спасява от грешки при заявки от позиция 1.
2. Копираме натрупаната сума.
За всяка позиция първо презаписваме стойността от предишната позиция (от индекс i-1).
3. Елегантно увеличаване чрез булеви изрази.
Изразите (curr == 1), (curr == 2) и (curr == 3) се преобразуват автоматично в число: дават 1, когато е истина, и 0, когато е лъжа. Така увеличаваме само точния масив.
4. Отговаряме на всяка заявка.
Използваме формулата за префиксни суми за всеки масив поотделно.

Ключов фрагмент от кода

for (int i = 1; i <= n; i++) {
    int curr;
    cin >> curr;

    // Копираме натрупаната сума от предишната позиция
    pref1[i] = pref1[i - 1];
    pref2[i] = pref2[i - 1];
    pref3[i] = pref3[i - 1];

    // Булевите изрази дават 1 (true) или 0 (false)
    pref1[i] += (curr == 1);
    pref2[i] += (curr == 2);
    pref3[i] += (curr == 3);
}
