ЗАДАЧА D3: Най-близките кратни

⏱️ Време: 1 с. 💾 Памет: 64 MB

Дадени са две цели числа N и d. Напишете програма multiples, която намира и извежда:

  1. Най-малкото цяло число, по-голямо или равно на N, което се дели на d без остатък.
  2. Най-голямото цяло число, по-малко или равно на N, което се дели на d без остатък.

Вход

На един ред на стандартния вход са зададени две цели числа N и d, разделени с интервал.

Изход

Програмата трябва да изведе на един ред на стандартния изход двете търсени числа, разделени с интервал.

Ограничения

0 ≤ N ≤ 1018
1 ≤ d ≤ 109

Пример

Примерен вход Изход за примера
13 5 15 10
💡 Указания (Подсказки)

Как да намерим кратните без цикли?

  • Предишно кратно: Търсим най-голямото число ≤ N. Можем да го намерим много бързо, като разделим целочислено N на d и след това умножим резултата обратно по d: (N / d) * d. Това автоматично отрязва остатъка!
  • Следващо кратно:
    - Ако N се дели точно на d (т.е. N % d == 0), то N е едновременно и предишното, и следващото кратно.
    - Ако не се дели точно, следващото кратно е просто предишното плюс d: ((N / d) * d) + d.
  • Типове данни: N е до 1018, така че използвайте long long.
